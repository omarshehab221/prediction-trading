BTC 5m prediction market trader

options:
  -h, --help            show this help message and exit
  --live                trade real money (pins the mode)
  --paper               simulate only (pins the mode)
  --preflight           probe endpoints with your keys and exit
  --calibration-report
  --diagnose            is the edge real? compares realised win rate against
                        the breakeven for the price paid
  --report-every REPORT_EVERY
                        log the calibration report every N settled trades;
                        useful when hosted, where the journal is hard to read
  --report-profile REPORT_PROFILE
                        restrict the report to one profile; default is every
                        profile in the journal, separately
  --profile {balanced,buffer,convex,favorite,lastminute,micro,scalp,straddle}
                        buffer = big buffer late in the round; micro = small
                        accounts (default); favorite = favourites; balanced =
                        symmetric; convex = longshots
  --scale-in            open small, then top up while the round stays
                        favourable (never after a loss)
  --no-scale-in
  --symbols SYMBOLS     comma-separated markets to RESTRICT trading to, e.g.
                        BTCUSDT,ETHUSDT. Default: none, meaning every 5m
                        up/down market the venue lists is discovered and
                        traded automatically. Each trades independently: its
                        own position slot, loss streak and calibration. Same
                        as the SYMBOLS environment variable; this flag wins if
                        both are set.
  --max-concurrent MAX_CONCURRENT
                        how many markets may hold a position at once
  --report-symbol REPORT_SYMBOL
                        restrict a report to one market
  --min-buffer MIN_BUFFER
                        override the buffer gate, in sigmas of the time
                        remaining
  --min-return MIN_RETURN
                        minimum net profit per unit staked on a win, after
                        fees; 0.25 means a win must pay at least 25% and caps
                        the fill price accordingly. 0 disables it.
  --trend-follow        enter earlier and stake more while the underlying
                        keeps running the same way
  --no-trend-follow
  --wait-for-auth WAIT_FOR_AUTH
                        seconds --preflight waits for a signed request to be
                        accepted, so a shared outbound IP can be added to
                        Binance's allowlist while it retries. Same as the
                        AUTH_WAIT_S environment variable; this flag wins if
                        both are set.
  --whoami              report the outbound IP actually in use and test
                        whether Binance accepts it
  --discover-min        probe the venue for its real minimum order size
                        (quotes only, places no order) and exit
  --fee-bps FEE_BPS     override the fallback fee rate; each market's own
                        published rate is preferred when available
  --min-edge MIN_EDGE
  --no-fat-tails        use a Gaussian model (understates cheap contracts)
  --kelly KELLY         override the profile's Kelly fraction
  --paper-bankroll PAPER_BANKROLL
                        paper starting balance; defaults to the profile's own
                        figure so micro does not simulate a 100 USDT account
                        it will never have
  --db DB
  --config CONFIG       configuration file; created with --write-config. Re-
                        read automatically whenever it changes.
  --write-config        write a complete config file with every setting at its
                        current value, then exit
  --print-default-profile
                        print the default profile name and exit
  --check-config        validate the config file and exit; touches no network
                        and no journal
  --no-hot-reload       read the config once and ignore later edits
  --verbose
